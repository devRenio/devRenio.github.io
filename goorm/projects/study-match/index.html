지원→매칭 전환율

6문항

평균 온보딩 완료 시간 2분

3개

후속 스터디 그룹 론칭

문제와 맥락

동아리 내 스터디 모집 공고는 많지만 실제 팀 결성까지 이어지는 비율이 낮았습니다. 지원자-리더 간 역량·시간대 불일치로 매칭 실패가 반복되었습니다.

핵심 의사결정

Decision 1

규칙 기반 필터 + 가중치 스코어링 하이브리드

검토한 대안
완전 LLM 매칭, 수동 엑셀 매칭
선택 이유
설명 가능성과 속도를 동시에 확보할 수 있었고, 베타 기간 데이터로 가중치를 조정할 수 있었습니다.
수용한 트레이드오프
복잡한 케이스에서는 추천 정확도가 다소 낮아질 수 있습니다.

Decision 2

매칭 이유를 3줄 요약으로 노출

검토한 대안
점수만 표시, 상세 리포트 PDF
선택 이유
사용자가 추천 결과를 신뢰하려면 '왜 매칭되었는지'가 필요했습니다.
수용한 트레이드오프
UI 공간을 더 사용했지만, 전환율 개선에 기여했습니다.

Decision 3

온보딩 설문을 6문항으로 제한

검토한 대안
12문항 상세 설문
선택 이유
베타 테스트에서 이탈률이 급증하는 지점이 7문항 이후였습니다.
수용한 트레이드오프
세밀한 매칭 정확도 일부를 포기했습니다.

결과

베타 2주 동안 48명이 참여했고, 팀 결성 성공률이 기존 수동 방식 대비 2배 이상 개선되었습니다. 매칭 이유 요약 UI가 사용자 신뢰도에 가장 큰 영향을 준 것으로 확인되었습니다.
